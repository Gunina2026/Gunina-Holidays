GUNINA HOLIDAYS WEBSITE
========================

Files included
--------------
1. index.html
2. style.css
3. script.js
4. gunina-holidays-logo.png
5. CNAME
6. README.txt

DOMAIN
------
The CNAME file is configured for:

www.guninaholidays.in

IMPORTANT
---------
Do not rename CNAME to CNAME.txt. It must be exactly:
CNAME

UPLOAD INSTRUCTIONS
-------------------
If you are using GitHub Pages:

1. Open the GitHub repository used for the website.
2. Upload all six files to the repository root.
3. Commit/save the changes.
4. In GitHub Pages settings, make sure the custom domain is:
   www.guninaholidays.in
5. Make sure the repository's Pages source points to the correct branch/folder.
6. Wait for GitHub Pages to publish the changes.

If you are using normal web hosting:

1. Open your hosting File Manager.
2. Go to the website's public_html (or document-root) folder.
3. Upload/extract the website files there.
4. Keep index.html, style.css, script.js and the logo in the locations expected by index.html.
5. The CNAME file is mainly required for GitHub Pages. Do not delete it if the site is deployed through GitHub Pages.

EXPECTED STRUCTURE
------------------
Gunina_Holidays_Website/
├── index.html
├── style.css
├── script.js
├── gunina-holidays-logo.png
├── CNAME
└── README.txt

AFTER UPLOAD
------------
Open:
https://www.guninaholidays.in/

If the browser shows an older version after uploading, do a hard refresh:
Windows: Ctrl + F5

If the layout looks broken, check that style.css is in the same directory as index.html.

If the mobile menu or enquiry form does not work, check that script.js is in the same directory as index.html and that index.html contains:
<script src="script.js"></script>

ENQUIRY FORM
------------
The website's enquiry form configuration is contained in index.html.
Do not remove the form fields or change its Web3Forms configuration unless you intend to change the form service.
