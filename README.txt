=======================

Web3Forms endpoint:
https://api.web3forms.com/submit

The form uses the Web3Forms access key configured in index.html. The access key must be associated with travel@guninaholidays.in in the Web3Forms account.

FORM FLOW
---------
Visitor clicks Enquire Now -> website enquiry form -> Web3Forms -> email notification.
The visitor stays on the website and sees a success/error message; there is no redirect to Web3Forms.
